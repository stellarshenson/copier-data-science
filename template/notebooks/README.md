# Notebooks

Jupyter notebooks for exploration, analysis, and reporting.

Organize notebooks in task-specific folders rather than as a flat list - one folder per task
(`exploration/`, `training/`, `evaluation/`, `experiments/`), created as needed. Number the
notebooks inside a folder in execution order (`01-data-exploration.ipynb`).

Import from `src/{{ module_name }}/` instead of redefining code in cells. Graduate stable code
into the module and keep only exploratory or one-off work here.
