# References

Reference material brought into the project from outside it - the resources the work builds on.

- Data descriptions and dictionaries - schemas, field meanings, collection notes
- Papers and their digests, in `papers/` (created as needed)
- Manuals, specifications, and vendor or API documentation
- Any other external resource the project depends on

Record where each item came from and why it is here. Documentation the project itself produces
belongs in `docs/`, not here.
